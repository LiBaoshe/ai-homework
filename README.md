# AI全栈开发实战营 毕业总结  
老学员一枚，在2021年学习过“Java进阶训练营”和“算法训练营2021版”，2025年6月15日加入了极客时间 彭靖田 老师的“AI全栈开发实战营”，经过两个多月的学习，了解了AI大模型的发展前景与关键技术。  
## 为什么选择训练营  
目前在云计算岗位做软件开发工程师，主要是云底座裸金属服务的特新开发、软件升级，主要语言有Java、Python。最近公司组织架构调整，面临裁员失业问题，想学习更多技术进入理想的公司。近两年AI的发展非常迅速，日常工作也能感受到AI带来的便利，想投身AI行业。也曾在B站看过一些关于AI的入门视频，感觉内容很多、很杂，有些讲的很浅，没有一个比较系统全面的视频。在对比了家培训机构的课程后，还是觉得极客时间的课程比较符合我的学习要求，因为已经在IT行业了，不需要从零基础开始学，AI专项学习省时省钱，再加上618活动的价格也比较优惠，故而选择了此训练营。  
## 课程收获  
课程中彭靖田老师讲的深入浅出，从深度学习理论基础到大模型实际应用，总体感觉还是比较好的，让我掌握了AI应用的发展方向和企业中的实战应用，实战课程还有作业来巩固知识。  
核心理论：机器学习基础、大模型原理（Transformer、MoE）、微调与蒸馏、主流模型对比。  
前沿技术：DeepSeek-R1、Qwen2.5、MCP、Dify 工作流编排、FastGPT、LangBot。  
实战向导：小红书文案生成/代码生成Agent，微信智能客服、企业级RAG、数据权限设计。  
行业赋能：金融、医疗、教育等多行业适配方法论。
